# Kesar Mithai Ghar (demo)

Demo website for a fictional sweet shop in Patna. Festive saffron, rani pink and green look with a polaroid photo collage, a tabbed rate list, a build-your-own gift box that writes the WhatsApp order, a Diwali countdown, reviews, FAQ and a bulk order form. Hindi switch.

Live: https://mohammadgulab.github.io/demo-sweets/

Design and code by Mohammad Gulab. Photos from Wikimedia Commons, credited in the page footer.
